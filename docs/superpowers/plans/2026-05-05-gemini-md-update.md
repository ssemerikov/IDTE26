# GEMINI.md - IDTE26 Проект з імерсивних технологій

## Огляд проекту
Цей репозиторій містить щотижневі лабораторні роботи з курсу **IDTE26 (Імерсивні/цифрові технології)**. Проект слідує прогресивному шляху навчання від базових сцен WebVR до просунутих досвідів доповненої реальності (AR) та розробки на чистому Three.js. Весь проект ведеться українською мовою.

### Ключові технології
- **A-Frame**: Основний фреймворк для сцен VR/AR (тижні 1–5). Локальна копія в `aframe/`.
- **AR.js**: Використовується для AR на основі маркерів (Hiro, Kanji та власні шаблони). Локальна копія в `AR.js-master/`.
- **MindAR**: Використовується для відстеження зображень-мішеней. Завантажується через CDN.
- **Three.js**: Введено на 6-му тижні для низькорівневої 3-D графіки. Завантажується через Import Maps.
- **Playwright**: Використовується для автоматизованого E2E тестування порталу та лабораторних робіт.
- **MSDF Fonts**: Підтримка власних українських шрифтів (`assets/times-msdf.json`).
```

## Запуск проекту
Проект складається зі статичних файлів HTML та JS. Для роботи AR та завантаження 3D-моделей **необхідно** використовувати локальний HTTP-сервер.

```

### Тестування
Для запуску автоматизованих тестів використовуйте:
```bash
npm install
npm run test:e2e
```

## Конвенції розробки
- **Без системи збірки**: Уникайте складних кроків збірки. Використовуйте чистий HTML/JS.
- **Управління активами**: Усі текстури, моделі, маркери (.patt) та файли MindAR (.mind) мають бути в папці `assets/`.
- **Підтримка української мови**: Завжди використовуйте MSDF шрифти з `negate="false"` для тексту A-Frame.
- **Локальні копії vs CDN**: A-Frame та AR.js переважно використовуються локально для стабільності, MindAR завантажується через CDN.
- **Three.js (Week 6+)**: Використовуйте Import Maps для сучасного робочого процесу ES-модулів без бандлера.
```
